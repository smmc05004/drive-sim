# drive-sim

경쟁이 없는 웹 기반 **운전 연습** 시뮬레이터. 실제 운전에 필요한 감각과 절차를 익히는 것이 목적이다.

> 레이싱 게임이 아니다. 1등이 목표가 아니라, 차선 변경 타이밍과 주차 절차를 몸에 익히는 것이 목표다.

## 현재 상태

**1단계 완료** — 공터 자유 주행.

핸들 각도 모델(±450°, 속도 감응 조향비), 크립·엔진 브레이크·앞뒤 제동 배분,
런타임 튜닝 패널과 텔레메트리, 깊이 단서를 갖춘 공터가 동작한다.

남은 것은 **실제로 몰아보고 조작감을 잡는 일**이다. 수치 기준은
`npm run verify:physics` 25개 항목으로 걸러지지만, "운전하는 느낌이 나는가"는
튜닝 패널로 직접 맞춰야 한다.

```bash
npm run dev              # 개발 서버
npm run verify:physics   # 브라우저 없이 물리·조작 모델 검증
npm run typecheck
```

### 조작

| 키 | 동작 |
|---|---|
| W / S | 가속 / 제동 (정지 상태에서 계속 누르면 D ↔ R 전환) |
| A / D | 핸들 — 누르는 동안 각도가 누적된다 |
| Space | 핸들에서 손 떼기 (자동 복원) |
| 화면 클릭 | 마우스 조향 (Pointer Lock, Esc 로 해제) |
| C | 운전석 ↔ 3인칭 시점 |
| R | 리스폰 |

우측 상단 **튜닝** 패널에서 모든 조작 수치를 실시간으로 바꿀 수 있다.
프리셋 저장/불러오기를 지원한다.
