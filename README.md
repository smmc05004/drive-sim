# drive-sim

경쟁이 없는 웹 기반 **운전 연습** 시뮬레이터. 실제 운전에 필요한 감각과 절차를 익히는 것이 목적이다.

> 레이싱 게임이 아니다. 1등이 목표가 아니라, 차선 변경 타이밍과 주차 절차를 몸에 익히는 것이 목표다.

## 현재 상태

**2단계 완료** — 차선 변경과 미러.

1단계 공터에 더해, 3차선 직선 도로에서 룸미러·좌우 사이드미러를 보며 차선을
변경하고 절차를 채점받을 수 있다. 미러는 실제 거울 크기에서 계산한 시야각을
쓰고, 좌우 반전이 정확하다.

남은 것은 **직접 몰아보고 판단하는 일**이다. 미러만 보고 뒤차와의 거리·접근
속도를 가늠할 수 있는지가 2단계의 진짜 완료 판정이다.

```bash
npm run dev              # 개발 서버
npm run verify:physics   # 브라우저 없이 물리·조작 모델 검증 (25항목)
npm run typecheck
```

### 조작

| 키 | 동작 |
|---|---|
| W / S | 가속 / 제동 (정지 상태에서 계속 누르면 D ↔ R 전환) |
| A / D | 핸들 — 누르는 동안 각도가 누적된다 |
| Space | 핸들에서 손 떼기 (자동 복원) |
| 화면 클릭 | 마우스 조향 (Pointer Lock, Esc 로 해제) |
| Z / X | 좌 / 우 방향지시등 |
| Q / E | 좌 / 우 어깨 너머 보기 (사각지대 확인) |
| 1 / 2 | 공터 / 도로 전환 |
| C | 운전석 ↔ 3인칭 시점 |
| R | 리스폰 |

우측 상단 **튜닝** 패널에서 모든 조작 수치를 실시간으로 바꿀 수 있다.
프리셋 저장/불러오기를 지원한다.
