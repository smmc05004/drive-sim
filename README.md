# drive-sim

경쟁이 없는 웹 기반 **운전 연습** 시뮬레이터. 실제 운전에 필요한 감각과 절차를 익히는 것이 목적이다.

> 레이싱 게임이 아니다. 1등이 목표가 아니라, 차선 변경 타이밍과 주차 절차를 몸에 익히는 것이 목표다.

## 현재 상태

**0단계 완료** — 셋업과 조작 루프.

평면 위의 박스 차량이 키보드로 움직인다. 운전석/3인칭 시점 전환, 고정 스텝 물리,
D/R 기어 전환까지 동작한다. 조작감 튜닝은 1단계에서 한다.

다음 작업: 1단계 — 공터 자유 주행과 조작감 튜닝.

```bash
npm run dev              # 개발 서버
npm run verify:physics   # 브라우저 없이 물리 검증
npm run typecheck
```

### 조작

| 키 | 동작 |
|---|---|
| W / S | 가속 / 제동 (정지 상태에서 계속 누르면 기어 전환) |
| A / D | 조향 |
| C | 운전석 ↔ 3인칭 시점 |
| R | 리스폰 |

## 기술 스택

Three.js (바닐라) + Rapier 3D (WASM) + Vite + TypeScript

선택 이유는 [개요 문서](./docs/OVERVIEW.md#기술-스택) 참조.
