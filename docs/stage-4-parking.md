# 4단계 — 빼곡한 주차장에서 차 빼기

> **검증 질문: 프로젝트의 목표가 달성되었는가?**

## 목표

양옆에 차가 빼곡히 주차된 상태에서 내 차를 빼낸다. 후진과 조향을 조합해 좁은 공간을 빠져나온다.

**이것이 프로젝트의 최종 목표다.** 1~3단계에서 만든 모든 것 — 조작감, 차폭 감각, 핸들 회전량, 미러, 긁힘 판정 — 이 전부 여기서 동시에 요구된다.

## 산출물

- 빼곡한 주차장 레벨 (전면/후면 주차, 평행 주차)
- 후진 조작과 후방 시야
- 핸들 감기/풀기 절차 안내와 채점
- 여러 난이도의 시나리오

## 왜 이 단계가 마지막인가

초보 운전자가 가장 두려워하는 상황이면서, 필요한 요소가 가장 많다.

| 필요 요소 | 어느 단계에서 준비되었나 |
|---|---|
| 저속 정밀 조작 | 3단계 |
| 크립 제어 | 1단계 → 3단계 검증 |
| 차폭·차체 감각 | 1단계 (실제 치수) → 3단계 |
| 핸들 회전량 인지 | 조향 모델 → 3단계 검증 |
| 미러로 간격 확인 | 2단계 → 3단계 |
| 긁힘 판정 | 3단계 |
| 후진 | **이 단계에서 신규** |

## 후진

### 기어 상태머신 검증

1단계에서 만든 D/N/R 전환이 여기서 집중적으로 쓰인다. **전진과 후진을 수십 번 반복**하는 상황이므로 전환이 답답하면 조작 전체가 무너진다.

- 전환 대기 시간(0.3s)이 적절한가
- 현재 기어 표시가 충분히 명확한가
- 잘못된 방향으로 나가는 사고가 없는가

### 후진 시 조향 감각

**후진에서는 핸들과 차의 움직임 관계가 직관에 반한다.** 이게 초보가 어려워하는 핵심이고, 이 게임이 가르쳐야 할 것이다.

- 후진 시에도 핸들 각도 표시를 유지 (오히려 더 중요)
- 조향 방향과 차 뒤쪽이 움직이는 방향을 시각적으로 보조하는 옵션 검토 (학습 초기용, 끌 수 있게)

### 후방 시야

| 수단 | 비고 |
|---|---|
| 룸미러 | 뒷유리 통해 |
| 사이드미러 | 하향 조정 기능 |
| 고개 돌려 뒤보기 | 키 하나로 카메라 회전. 실제와 같이 이 동안 전방이 안 보임 |
| 후방 카메라 | 요즘 차는 대부분 있음. 옵션으로 켜고 끄기 — **끄고 연습하는 것이 학습 가치가 높다** |

## 레벨 시나리오

실제 치수 참고:

| 요소 | 실제 치수 |
|---|---|
| 일반 주차 구획 | 2.5m × 5.0m |
| 확장형 주차 구획 | 2.6m × 5.2m |
| 평행 주차 구획 | 2.0m × 6.0m |
| 주차 통로 폭 (직각주차) | 6.0m 이상 |
| 승용차 크기 | 1.8m × 4.4m |

구획 2.5m에 차폭 1.8m면 **좌우 여유가 35cm씩**이다. 문을 열기도 빠듯한 이 수치가 초보의 공포의 근원이고, 게임에서 임의로 넓히면 안 되는 이유다.

### 난이도 구성

| 시나리오 | 구성 | 학습 목표 |
|---|---|---|
| 1. 한쪽만 차 있음 | 옆에 차 1대 | 기본 후진 감각 |
| 2. 양옆 차 있음 | 좌우 각 1대, 통로 넓음 | 좌우 여유 관리 |
| 3. 통로가 좁음 | 통로 5.5m | 꺾어 나오기 |
| 4. 앞에도 장애물 | 기둥 또는 벽 | 전후진 반복 (切り返し) |
| 5. 평행 주차에서 빼기 | 앞뒤 차 밀착 | 최고 난이도 |

## 핸들 절차 채점 — 이 게임의 정체성

여기가 다른 운전 게임과 가장 크게 갈리는 지점이다. **"차를 뺐다"가 아니라 "올바른 절차로 뺐다"를 채점한다.**

조향 모델에서 핸들 각도를 1급 상태값으로 만든 이유가 여기서 회수된다.

### 채점 항목

- 후진 시작 전 주변 확인 여부
- 핸들을 감기 시작한 시점 (너무 이르거나 늦지 않았는가)
- 감은 양 (풀락까지 감았어야 하는데 절반만 감았는가)
- 푸는 시점과 양
- 전후진 전환 횟수 (적을수록 능숙)
- 긁힘 횟수
- 소요 시간 (참고용. 경쟁 요소로 만들지 않는다)

### 안내 모드

학습 초기에는 **다음에 해야 할 조작을 안내**한다.

> "핸들을 오른쪽으로 끝까지 감으세요" → (감김 완료) → "천천히 후진하세요" → "차가 절반 나오면 핸들을 반 바퀴 푸세요"

핸들 각도가 상태값이므로 "끝까지 감았는지", "반 바퀴 풀었는지"를 정확히 판정할 수 있다.

안내를 끄고 스스로 하는 모드로 졸업한다.

### 리플레이

시도 후 위에서 내려다본 시점으로 궤적과 핸들 조작을 재생한다. **자기가 무엇을 했는지 보는 것이 가장 효과적인 학습**이다. 실차 연습에서는 불가능한, 시뮬레이터의 고유 가치다.

## 완료 판정

- [ ] 5개 시나리오를 모두 클리어할 수 있다 (연습하면)
- [ ] 후진 시 조향 방향이 혼란스럽지 않다
- [ ] 미러와 뒤보기만으로(후방 카메라 없이) 뺄 수 있다
- [ ] 핸들 절차 채점이 납득 가능하다
- [ ] 안내 모드가 실제로 도움이 된다
- [ ] 리플레이로 자기 조작을 확인할 수 있다
- [ ] **이 게임으로 연습하면 실제 주차가 덜 무서워질 것 같다** — 최종 판단

## 리스크

| 리스크 | 대응 |
|---|---|
| 저속 정밀 조작이 여전히 불안정 | 3단계 완료 판정을 엄격히 적용. 여기서 해결하려 하면 늦다 |
| 절차 채점이 지나치게 엄격/관대 | 실제 운전 교육 커리큘럼 참고, 사용자 피드백으로 조정 |
| 후진 조향 방향을 여전히 헷갈림 | 보조 표시의 강도를 단계적으로 조절하는 학습 곡선 설계 |
| 실차 감각과 괴리 | 치수를 절대 임의로 넓히지 않는다. 괴리가 생기면 게임의 존재 이유가 사라짐 |

## 이 단계 이후

프로젝트의 원래 목표는 여기까지다. 이후 확장 후보:

- 곡선 도로, 교차로, 좌우회전
- 주차하기 (빼기의 역방향)
- 야간·우천 등 시야 조건
- 다양한 차종 (차폭·회전 반경이 다른 차)

다만 **확장보다 기존 4단계의 완성도가 우선**이다. 감각이 정확하지 않은 컨텐츠를 늘리는 것은 학습에 해롭다.
