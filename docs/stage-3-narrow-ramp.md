# 3단계 — 좁은 램프와 정밀 조작

> **검증 질문: 긁지 않고 통과하는 정밀 조작이 되는가?**

## 목표

폭이 좁은 주차장 램프를 긁지 않고 오르내린다. 벽과 기둥 사이를 아슬아슬하게 통과한다.

여기서부터 **차폭 감각과 핸들 회전량**이 실제로 요구된다. 1~2단계는 판단이 중심이었지만, 이 단계부터는 조작 정밀도가 중심이다.

## 산출물

- 좁은 나선형/직선형 램프 (경사 + 곡선)
- 기둥, 벽, 연석
- 긁힘 판정과 피드백
- 저속 전용 조작 파라미터
- 사이드미러를 이용한 차체 위치 확인

## 저속 정밀 조작 재튜닝 — 이 단계의 최대 리스크

**레이캐스트 차량은 저속·풀조향에서 떨리거나 미끄러지기 쉽다.** 1단계에서 40~60km/h 위주로 튜닝했다면 5~15km/h 영역은 별도 검증이 필요하다.

### 증상과 대응

| 증상 | 원인 후보 | 대응 |
|---|---|---|
| 정차 상태에서 차가 부르르 떨림 | 횡방향 마찰이 정지 마찰을 표현 못 함 | 저속에서 횡방향 강성 증가, 속도 임계값 이하에서 잔여 속도 감쇠 |
| 풀조향 시 앞바퀴가 미끄러짐 | frictionSlip 부족 | 저속 구간에서 마찰 상향 |
| 경사로에서 뒤로 밀림 | 크립·브레이크 부족 | 오토 차량의 힐 홀드 동작 재현 검토 |
| 저속에서 조향이 둔함 | 조향비가 속도 감응으로 커져 있음 | 속도 감응 곡선의 저속 구간 확인 |

**속도 구간별 파라미터 세트를 분리하고 보간**하는 방식을 검토한다. 하나의 파라미터 세트로 5km/h와 80km/h를 모두 만족시키기는 어렵다.

### 크립이 주역이 된다

실제로 좁은 램프에서는 액셀을 거의 밟지 않는다. **크립으로 굴러가면서 브레이크로 속도를 조절**한다. 1단계에서 넣어둔 크립을 이 단계에서 실전 검증한다.

- 경사로에서 크립만으로 올라갈 수 있는가
- 내리막에서 브레이크만으로 안정적으로 속도를 유지할 수 있는가

## 레벨 설계

**물리보다 노가다가 많은 단계다.** "긁힐 듯 말 듯"한 폭을 만드는 건 반복 조정으로만 나온다.

### 데이터로 분리한다

램프 형상, 기둥 위치, 폭을 JSON 등 데이터로 정의하고 코드와 분리한다. 조정 반복이 확정되어 있으므로 초기 투자가 회수된다.

### 실제 치수 참고

| 요소 | 실제 치수 |
|---|---|
| 주차장 램프 차로 폭 (직선) | 3.3m 이상 |
| 곡선 램프 차로 폭 | 3.6m 이상 |
| 램프 경사 (직선) | 17% 이하 |
| 램프 경사 (곡선) | 14% 이하 |
| 곡선 램프 내측 회전 반경 | 6m 이상 |
| 일반 승용차 폭 | 1.8m |

차폭 1.8m에 차로 3.3m면 좌우 여유가 0.75m씩이다. **실제로 초보에게 어려운 이유가 수치로 드러난다.** 게임에서 임의로 넓히면 학습 가치가 사라지므로 실제 치수를 지킨다.

### 깊이 단서 강화

좁은 공간에서는 여유 폭 가늠이 전부다.

- 기둥·벽 모서리에 줄무늬 또는 대비색
- 연석 강조
- 벽면에 규칙적인 패턴 (거리 판단)
- 그림자를 확실히 (차와 벽의 상대 위치)

## 긁힘 vs 충돌 판정

Rapier의 충돌 이벤트에서 **충격량(impulse)과 접촉 각도**로 구분한다.

| 판정 | 조건 | 피드백 |
|---|---|---|
| **스침 / 긁힘** | 충격량이 작고, 접촉면에 대해 스치는 방향 | 긁는 소리, 화면 미세 흔들림, 긁힘 카운트 증가 |
| **충돌** | 충격량이 임계값 이상 | 충돌음, 화면 강한 흔들림, 시도 실패 |

임계값은 튜닝 대상이며 튜닝 패널에 노출한다.

### 피드백이 학습의 핵심

긁혔을 때 **어디를 긁었는지** 알려줘야 한다. 실차에서는 소리와 진동으로 알지만 위치 파악이 어렵고, 이 게임에서는 그걸 명확히 보여줄 수 있다 — 시뮬레이터가 실차보다 나은 지점이다.

- 차량 모식도에 긁힌 부위 표시
- 리플레이로 그 순간을 외부 시점에서 재생
- "우측 앞 휀더가 기둥에 0.3m 부족했습니다" 같은 구체적 수치

## 사이드미러의 새로운 용도

2단계에서 미러는 "뒤차 확인"용이었다. 여기서는 **"내 차체와 벽 사이 간격 확인"**용이다. 실제 운전자가 좁은 곳에서 하는 행동과 같다.

## 아커만 조향 도입

좁은 곳 저속 선회에서는 안쪽/바깥쪽 바퀴의 조향각 차이가 궤적에 눈에 띄게 영향을 준다. 이 단계에서 도입한다.

## 완료 판정

- [ ] 저속(5~15km/h)에서 차가 떨리지 않는다
- [ ] 풀조향 상태로 저속 선회가 안정적이다
- [ ] 경사로에서 크립만으로 오를 수 있고, 뒤로 밀리지 않는다
- [ ] 실제 치수의 램프를 긁지 않고 통과할 수 있다 (연습하면)
- [ ] 긁힘과 충돌이 구분되어 판정된다
- [ ] 긁힌 부위를 알 수 있다
- [ ] 미러로 차체와 벽 사이 간격을 가늠할 수 있다
- [ ] **핸들을 얼마나 감았는지 감각으로 안다** — 조향 모델의 실전 검증

## 리스크

| 리스크 | 대응 |
|---|---|
| 저속 떨림이 해결되지 않음 | 물리 스텝 세분화(1/120), 정지 마찰 별도 처리, 최악의 경우 저속에서 물리 대신 운동학적 처리 검토 |
| 레벨 조정에 시간이 과다 소요 | 데이터 분리 + 인게임 편집 도구 검토 |
| 긁힘 판정이 부정확 (안 긁었는데 긁힘 판정) | 콜라이더 형상을 차체에 맞게 세분화 (단일 박스 → 복합 형상) |
